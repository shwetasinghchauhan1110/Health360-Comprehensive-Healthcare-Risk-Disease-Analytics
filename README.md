# Health360-Comprehensive-Healthcare-Risk-Disease-Analytics
An end-to-end cloud-native data analytics platform that ingests, cleanses, and processes 5,000+ patient records using Snowflake and Python. Features automated median imputation, composite multi-disease risk scoring (0–100 scale), and interactive Tableau dashboards for real-time clinical decision support and triage.
